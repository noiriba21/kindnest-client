# KindNest 🐦 – Social Development Events Platform
🔗 **Live site:** https://kindnest-client-mauve.vercel.app/
KindNest is a community platform where neighbours create, join and track social service events such as winter clothes distribution, tree plantation and beach cleanups.

## Features
- Create, update and delete your own community service events (only the owner can edit or delete)
- Join events and see them sorted by date on your Joined Events page
- Secure login with email and password or GitHub, with JWT protected APIs
- Light and dark theme toggle that remembers your choice
- Kindness Points and badges (Seedling, Helper, Hero) that reward helpful neighbours
- Quotes of Kindness from many faiths, search and type filter, loading skeletons and profile update
- Fully responsive for mobile, tablet and desktop

## Tech
Next.js (App Router), Tailwind CSS, DaisyUI, BetterAuth, MongoDB, Express.js, JWT
